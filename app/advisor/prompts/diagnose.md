command: diagnose
name: Diagnose
---
Diagnose this problem.

Symptom: {{symptom}}

Answer in this order:
1. Checks: the read-only commands to run first, each in a code block, and what each result means.
2. Likely cause: the most probable one, with the evidence that would confirm it.
3. Fix: numbered steps.
4. Undo: how to reverse each step of the fix.
