Plan this change.

Goal: {{goal}}

Answer in this order:
1. Goal: restate it in one sentence, with any assumption you made.
2. Risks: what could break or be lost, and how likely it is.
3. Steps: numbered, with the command for each and where it runs.
4. Rollback: how to return to the current state at each step.
5. Verification: how to confirm it worked, with expected output.
